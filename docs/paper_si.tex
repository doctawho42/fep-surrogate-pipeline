\paragraph{Synthetic decomposition (illustration).} A controlled 1-D problem where the
generative structure is known shows the decomposed interval is up to $2.2\times$ sharper vs split-conformal ($2.0\times$ vs CQR) at equal coverage with better conditional calibration; this is an illustration of the
mechanism, not evidence on real data (Figure~\ref{fig:Breal} is the real test).

\paragraph{Edge weighting (Figure~\ref{fig:C}).} The acquisition policy beats random
($2.2\times$), but sandwich-vs-naive edge \emph{weighting} barely moves calls-to-top-$k$
($0.98\times$ $[0.93,1.03]$, 24-seed bootstrap CI): the Gauss--Markov ceiling.

\paragraph{Ligand-only target identification (Figure~\ref{fig:F}).} On real ChEMBL reverse
screening, a fingerprint model ties, but does not beat, a Tanimoto baseline (top-1
$0.84$--$0.97$ vs $0.86$--$0.96$), though $P(\text{binds})$ is well calibrated (ECE $0.008$).
Beating similarity needs orthogonal 3D/pocket information.

\paragraph{Chirality completeness on a real molecule (Figure~\ref{fig:Ereal}).}
Theorem~\ref{thm:chiral} is instantiated on thalidomide, the textbook case where the two
enantiomers differ in biological activity. We embed one enantiomer in 3D (RDKit) and reflect it
to the exact mirror geometry. Every O(3)-invariant readout is identical on the pair: all $171$
pairwise distances and all pairwise dot products (the Gram matrix) match to machine precision
($\max|\Delta|=0$), so a norm-and-dot-product readout is enantiomer-blind. The parity-odd
\texttt{0o} pseudoscalar $\chi=\det[p_1{-}p_0,p_2{-}p_0,p_3{-}p_0]$ flips sign
($+1.037\to-1.037$), and RDKit's CIP assignment flips $R\to S$. This reproduces, on real
chemistry, the collapse-and-restore of the chirality bit proved for the designed test set
(Figure~\ref{fig:E}). Deterministic; \texttt{make figEreal}.

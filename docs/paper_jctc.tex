\section*{Data and Software Availability}
All data are public: the alchemtest BACE1 and benzene alchemical sets, the OpenFF
protein--ligand benchmark (which aggregates the FEP+ and Merck data sets), and ChEMBL. The BAR
layer, the surrogate, the theorem-verification unit tests, and every figure-regeneration
script are released as open source; each figure is reproduced by a single command (for
example, \texttt{make figJ}).

\begin{suppinfo}
